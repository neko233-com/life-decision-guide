# 行动计划

阶段入口是 `/plans`。正文保存为 [content/plan-foundation.html](../content/plan-foundation.html) 与 `content/plan-a5.html` 至 `content/plan-a12.html`，共 9 篇，均为本站原创框架。

## 口径与区间

家庭净资产 = 总资产 − 总负债，含自住房，使用人民币与同一估值日期。房屋参考市值计资产，未还房贷计负债，只扣 1 次。企业权益按家庭持有部分估值，不重复加入公司总资产；年收入不直接计为资产。或有担保责任另列风险。

本页 A 编号按金额位数标记；区间含下限、不含上限。这是阅读标签，不是官方财富标准、产品准入、能力评定或收益承诺。

| 分组 | 标签 | 人民币净资产区间 | 重点 |
| --- | --- | --- | --- |
| 起步与积累 | A5 起步 | 1万–不足10万元 | 备用金、稳定收入 |
| 起步与积累 | A6 积累 | 10万–不足100万元 | 现金流、赚钱能力 |
| 起步与积累 | A7 家庭底盘 | 100万–不足1000万元 | 住房、保障、长期目标 |
| 配置与保护 | A8 稳健配置 | 1000万–不足1亿元 | 分散风险、资产规则 |
| 配置与保护 | A9 家企分开 | 1亿–不足10亿元 | 家庭与企业责任边界 |
| 家族与机构治理 | A10 专业协作 | 10亿–不足100亿元 | 职责、授权、监督 |
| 家族与机构治理 | A11 家族治理 | 100亿–不足1000亿元 | 家族规则、管理交接 |
| 家族与机构治理 | A12 机构治理 | 1000亿–不足1万亿元 | 持续运作、独立复核 |

低于 1 万元、净负债或尚未盘点时看基础计划；达到 1 万亿元后按实际复杂程度继续看治理内容。现金紧张、收入不稳定、近期大额支出和供养责任可改变优先级，资产档位不直接决定配置。

## 编辑与依据

[src/plans.js](../src/plans.js) 保存区间、3 组、短名称与重点；[src/Plans.jsx](../src/Plans.jsx) 提供选择入口。改范围或重点时同时核对相应 HTML。正文编辑 `content/plan-*.html`，不要编辑生成数据。

每档包含 3 个重点、30 / 90 天行动、6 个生活模块、示例、进展检查和相关阅读。行动节奏是示例，具体措施需要按情况调整。法律效力、地区政策与医疗选择另行核对，不凭档位指定比例、产品或复杂法律结构。

共同原则的参考集中在基础计划：

- [CFPB 应急资金指南](https://www.consumerfinance.gov/an-essential-guide-to-building-an-emergency-fund/)：应急资金、个人情况与及时可用性。
- [SEC Investor.gov 配置与分散](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)：时间、风险和底层分散。
- [IFC 家族企业治理手册](https://www.ifc.org/en/insights-reports/2011/ifc-family-business-governance-handbook)：角色、治理和管理交接。

整理日期 2026-10-05。前 2 项是美国机构的一般原则，不用于断言中国税收、资格或产品保障。区间、优先级和情境是本站编辑建议，不能说成由这些机构推荐。

## 验证

先 `npm run build`，再 `npm run verify`。检查 8 档边界（如 10 万元进入 A6、1000 万元进入 A8）、每档步骤与模块、链接、搜索及折叠原文。浏览器在 1440px、390px 和 320px 检查选择、返回、计划全文与来源定位。
