# 设计约定

让读者先看懂，再决定是否展开。每个区域只回答一个问题，避免重复介绍和密集说明。

## 视觉

使用系统无衬线字体：SF、PingFang 和相应系统回退。背景为白色，辅助面为 `#f5f5f7`，正文为 `#1d1d1f`，交互蓝色为 `#0071e3`。

页面依靠留白、字重和清晰分组建立层次。首页使用一个短标题、一句介绍、两个动作和宽幅山景。正文采用列表与分隔线，输入或展开区域才使用圆角背景。导航保留轻微玻璃效果。

`src/apple.css` 在基础与搜索样式之后加载。动画应快速、轻微，并尊重 `prefers-reduced-motion`。

## 文案与阅读层级

- 标题说清动作或问题，建议不超过 24 字。
- 一句话解释怎么做或何时做，建议不超过 60 字。
- 为保留必要条件，标题可到 28 字，摘要可到 75 字。
- 不重复标题，不堆术语，不使用装饰性口号解释日常功能。
- 医疗禁忌、剂量条件、法律地区与期限、金融风险不能因精简而丢失。
- 原文不确定的结论仍保留条件，不能新增无依据的保证或建议。

参考章节先用问题导读和分组入口帮助定位；每组第 1 条预览一句话，其余条目显示短标题。展开后显示一句话，再展开“依据与原文”查看原始标题、六字段与引用。补充文档先显示要点，完整说明放在折叠区。来源始终可查看，搜索继续覆盖原文。短版中的数字优先使用阿拉伯数字。

评分 1–5 分均表示“越符合越高”；权重另表示重要程度。结果显示 100 分制、5 分制和贡献分，并明确分数不是成功概率。费用和风险标准写成“可承受”“可接受”，避免评分方向相反。

## 验收

在 1440px 桌面和 390px、320px 手机检查首页、列表、文章、评分和搜索。正文与控件不得导致页面横向溢出；评分表允许在自己的容器内滚动。检查首屏文字层级、焦点、点击区域和控制台错误。

搜索测试包括 Ctrl / ⌘ + K、方向键、Enter、Escape、无结果、追加结果，以及手机输入。搜索原始标题和字段词，点击后确认锚点与折叠定位。

评分至少验证：权重 `5、3、0` 下，分数 `5、3、0` 得 `85 / 100`（`4.25 / 5`），`3、5、0` 得 `75 / 100`（`3.75 / 5`）；全零权重不计算；未填写不产生优胜方案；并列方案同时显示；刷新后记录保留；Markdown 可导出。

短版验收应按章抽查原文，覆盖医疗、急救、法律、财务、育儿和用药内容。构建验证证明结构和保留情况，人工阅读检查含义。
